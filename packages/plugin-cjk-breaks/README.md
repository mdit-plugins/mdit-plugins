## [Docs](https://mdit-plugins.github.io/cjk-breaks.html) | [文档](https://mdit-plugins.github.io/zh/cjk-breaks.html)

## Install / 安装

```bash
# pnpm
pnpm add -D @mdit/plugin-cjk-breaks
# npm
npm i -D @mdit/plugin-cjk-breaks
# yarn
yarn add -D @mdit/plugin-cjk-breaks
```
