[![Version](https://img.shields.io/npm/v/@mdit/plugin-frontmatter.svg?style=flat-square&logo=npm) ![Downloads](https://img.shields.io/npm/dm/@mdit/plugin-frontmatter.svg?style=flat-square&logo=npm) ![Size](https://img.shields.io/bundlephobia/min/@mdit/plugin-frontmatter?style=flat-square&logo=npm)](https://www.npmjs.com/package/@mdit/plugin-frontmatter)

Frontmatter plugin for MarkdownIt.

## [Docs](https://mdit-plugins.github.io/frontmatter.html) | [文档](https://mdit-plugins.github.io/zh/frontmatter.html)

## Install / 安装

```bash
# pnpm
pnpm add -D @mdit/plugin-frontmatter
# npm
npm i -D @mdit/plugin-frontmatter
# yarn
yarn add -D @mdit/plugin-frontmatter
```
