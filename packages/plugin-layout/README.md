# @mdit/plugin-layout

[![Version](https://img.shields.io/npm/v/@mdit/plugin-layout.svg?style=flat-square&logo=npm) ![Downloads](https://img.shields.io/npm/dm/@mdit/plugin-layout.svg?style=flat-square&logo=npm) ![Size](https://img.shields.io/bundlephobia/min/@mdit/plugin-layout?style=flat-square&logo=npm)](https://www.npmjs.com/package/@mdit/plugin-layout)

A directive-based layout engine plugin for MarkdownIt supporting Flexbox, CSS Grid, and Multi-column layouts.

## [Docs](https://mdit-plugins.github.io/layout.html) | [文档](https://mdit-plugins.github.io/zh/layout.html)

## Install / 安装

```bash
# pnpm
pnpm add -D @mdit/plugin-layout
# npm
npm i -D @mdit/plugin-layout
# yarn
yarn add -D @mdit/plugin-layout
```
