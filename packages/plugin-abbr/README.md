## [Docs](https://mdit-plugins.github.io/abbr.html) | [文档](https://mdit-plugins.github.io/zh/abbr.html)

## Install / 安装

```bash
# pnpm
pnpm add -D @mdit/plugin-abbr
# npm
npm i -D @mdit/plugin-abbr
# yarn
yarn add -D @mdit/plugin-abbr
```
